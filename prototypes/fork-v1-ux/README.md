# ChatAtlas Fork V1 — 低保真交互原型

本目录是可丢弃的原型，不是正式功能实现。验证问题是：第一轮 UX
访谈中选定的地图、单轮阅读、输入与路径操作，组合起来能否支撑三个完整任务？

## 启动

在仓库根目录运行，不需要安装额外依赖或启动正式服务：

```powershell
node prototypes/fork-v1-ux/serve.mjs
```

打开 <http://127.0.0.1:4178>。关闭启动窗口中的服务用 Ctrl+C。
如果提示端口已被占用，而原型页面可以正常打开，说明已有服务在运行，无需重复启动。
如果端口由其他程序占用，或确实需要另开服务：

```powershell
$env:PROTOTYPE_PORT = '4179'
node prototypes/fork-v1-ux/serve.mjs
```

也可以双击 `index.html` 离线使用。建议验证期间固定使用上面的 localhost
地址：不同端口、浏览器或 file:// 地址的本地状态不共用。

## 三条完整流程

顶部“验证流程”（侧栏底部也有入口）选择相应演示，再依次点击画布底部引导中的“执行此步骤”。这些按钮调用
与自由操作相同的创建、编辑、Fork、提交和导航操作，没有独立的假成功界面。
可随时直接使用实际输入框、节点和导航。等待模拟输出时可选“快进模拟回复”。

1. **探索替代方案**：从空白演示开始 New Chat，提交首轮、继续两轮，
   从第二轮 Fork，编辑并提交替代方案，再切回原对话。
   检查原 Conversation 仍有三轮，分支只继承截至第二轮的同一批 Turn。
2. **分出去学习概念**：从已有三轮对话中选第二轮，准备概念学习草稿，
   提交后在学习分支继续，再回原路径。检查原内容、身份和阅读位置。
3. **并行推进多个方向**：从同一及不同起点创建三份草稿，切走再恢复，
   分别提交其中两份；另一份继续保留。检查两条分支独立生成，后台完成提示
   不改变当前选择；随后在一条分支准备续写。

“自由探索”及三个引导使用独立演示数据集，每份数据集内有独立的多个 Project。
验证流程入口是测试工具，项目选择器才是产品导航。切换演示时保留各自进度。
“从头重演”创建新的一次演示，不删除之前的模拟状态。完成引导不等于用户已验证设计。

以下入口与代理走查时的模拟内容隔离；首次打开从该流程起点开始，以后会恢复进度：

- [① 探索替代方案](http://127.0.0.1:4178/?workspace=a-user)
- [② 分出去学习概念](http://127.0.0.1:4178/?workspace=b-user)
- [③ 并行推进多个方向](http://127.0.0.1:4178/?workspace=c-user)

窄窗口和专注阅读时，可通过顶部项目名称切换 Project，用“项目导航”恢复当前项目的对话与草稿。
验证流程入口也可从“项目导航”对话框进入。较宽的桌面窗口显示常驻侧栏项目选择器。

## 按 Project 管理与恢复

项目导航补充访谈已确认三项：侧栏顶部常驻项目切换器；待发送只显示当前项目；
返回项目时恢复完整工作现场。原型预置“产品设计”和空白“英语学习”，支持只填名称
新建空白项目。示例名称和最小新建表单是原型素材与假设，不是最终项目管理设计。

可自行验证：

1. 在“产品设计”从历史 Turn 准备 Fork 草稿，输入文字，调整缩放、折叠或阅读位置。
2. 用侧栏顶部选择器进入“英语学习”。应看不到另一个项目的 Turn、Conversation 或草稿；待发送从零开始。
3. 在“英语学习”New Chat，输入另一段文字，切回“产品设计”；原草稿和地图、阅读现场应恢复。
4. 再次切换，确认两个项目各自恢复。可分别进入专注阅读、刷新，再确认所选项目和各自现场保留。

New Chat 在当前 Project 中创建独立路径；Fork 和普通续写留在当前项目。切换项目
不会自动提交、取消草稿或触发地图全图缩放。项目各自保存选择、路径、视口、折叠、
位置撤销历史、阅读位置及阅读模式。项目重命名、删除、跨项目移动及共享不在本轮。

## 可实际操作的交互

- 选择 Turn 看完整 Prompt/回复；节点只显示节选，正文可以选文。
- New Chat、Fork、普通续写各自具有画布输入卡与阅读区编辑器，内容同步。
- 任意正常完成 Turn 可以 Fork；同一起点可创建多份独立草稿。
- Fork 草稿显示并高亮根至起点的完整继承历史；不会复制原 Turn 身份。
- 点击独有节点切换当前路径；点击共享节点仅阅读，继续时弹出路径选择器。
- 通过对话路径导航恢复该路径上次阅读的 Turn；阅读滚动位置按 Turn 保存。
- 手动收起整个下游及草稿，入口提示隐藏轮次、待发送及生成任务。
- 导航到隐藏内容会展开必要层级，其他折叠状态不变。
- 拖标题移动单个对象；节点 `⋯` 明确选择整个下游后，可拖标题一起移动。
- `V` 选择，`H` 抓手；空格或鼠标中键拖动平移；滚轮平移，Shift+滚轮横移，
  Ctrl+滚轮在鼠标位置缩放。输入框里的按键用于文字编辑。
- Ctrl+Z / Ctrl+Shift+Z（或 Ctrl+Y）撤销/重做位置调整；输入框内使用浏览器文字撤销。
- 并排和专注阅读切换；返回时保留缩放，只在必要时平移使当前节点可见。
- 模拟流式输出，向上回看时停止跟随，点击“回到最新内容”恢复。
- 可以停止单项生成；不会停止其他任务。正常、失败、截断等实际结束状态保留。
- 草稿的“原型模拟条件”可触发提交前拒绝、部分输出失败、零输出失败和截断。
  拒绝时就地显示原因，草稿保留，不先创建正式 Conversation。
- 路径默认以首个新增 Prompt 的节选命名，可在阅读区“记录信息”中修改。
- 非空未提交内容放弃前确认；空白直接移除，不删除正式历史。
- “状态”提供可读的身份、各条路径、继承上下文及最近状态变化。

## 已确认的规则

来源：2026-11-16 本聊天的第一轮 UX 访谈 Q1–Q35，以及当前
[GLOSSARY](../../GLOSSARY.md)、[ADR-0001](../../docs/adr/0001-share-turn-history-across-conversations.md)、
[ADR-0002](../../docs/adr/0002-persist-fork-drafts-before-conversation-creation.md)、
[Fork V1 Spec](../../.scratch/fork-v1/spec.md)。当前请求确认本轮只验证原型，不改这些基线。

| 范围 | 已确认选择 |
| --- | --- |
| 核心场景 | 替代方案、概念学习、并行探索均为主要场景 |
| 项目组织 | 常驻项目切换器；项目内组织地图、对话、分支与待发送内容 |
| 项目切换 | 待发送仅当前项目；返回完整恢复各自工作现场 |
| 阅读与节点 | 并排与专注都支持；默认单 Turn；卡片显示 Prompt/回复节选 |
| 布局 | 从左往右推进，Fork 向下；自动找空位，已有位置稳定 |
| 手动整理 | 可移动节点或分支；默认拖标题只移动单个节点，正文选文 |
| 输入 | 三类输入双处同步；New Chat/Fork 可多份，续写每个 Conversation 一份 |
| 导航 | 独有节点自动切路径；共享节点先阅读、继续时再明确选择路径 |
| 继承 | 编辑 Fork 草稿时默认突出根至起点，标明截止位置；专注模式也保留提示 |
| 折叠 | 用户手动控制；包含全部下游与草稿；入口有数量和任务提示 |
| 恢复 | 统一待发送入口；定位时展开必要层级；重开恢复工作现场 |
| 生成 | 提交后进入新 Turn；主动回看暂停跟随；后台结果轻提示，不抢焦点 |
| 反馈 | Fork 不可用时置灰；提交拒绝就地说明；非空输入放弃前确认 |
| 撤销 | 文字编辑和画布位置按焦点分开；不将正式 Turn 提交作为普通撤销对象 |

## 原型假设：仍需亲自验证

- 左导航 / 中央画布 / 右阅读区的比例，卡片宽高、空位算法、分支间距和连线样式。
- 路径选择对话框、“待发送”列表、卡片 `⋯` 下游选择入口的具体位置与文案。
- 从导航定位任意隐藏内容时展开祖先；折叠包含当前选择时，阅读选择回到折叠入口。
- 节点的“继续”可以从阅读位置发起，但新增位置始终是所选 Conversation 末尾。
- 回复模拟速度、通知显示时长；这些数值没有经过体验验证。
- 每个验证任务提供独立模拟数据集；数据集内才是实际项目切换，二者的入口分开。
- 项目的示例名称、只填名称的新建表单与控件文案仍待验证。
- 切到其他项目时，模拟生成在所属项目后台继续；通知带项目名，点击后才切项目定位。这是跨项目通知假设。
- 原型刷新后会继续演示未完成模拟输出，不表示正式应用已决定崩溃后的生成恢复策略。

## 隔离与限制

- 单一 HTML，内联 CSS/JS，无外部资源、正式模块导入、API、模型或数据库。
- `serve.mjs` 仅在 127.0.0.1 提供这一个文件，没有业务接口或写文件接口。
- 使用 `chatatlas-ux-prototype-v1:` 前缀的 localStorage；保存输入、模拟历史、
  选择、视口、折叠、阅读位置和模式。只属于该浏览器源，非可靠数据备份。
- 旧版单项目模拟状态首次载入时原样归入“产品设计”，并保留一份 `legacy:` 本地副本；不会清空原有对话和草稿。
- 模型不可用和容量超限只是可控的交互开关，不执行真实模型能力或 Token 校验。
- 输入文字撤销依赖当前浏览器编辑会话；两处编辑器的文字撤销栈不共用。
- 暂不实现框选、吸附对齐、节点缩放、触屏手势、多模态或 Conversation 删除。
- 正式入口、依赖、Ticket 01 代码、领域文档或 Tickets 不属于本原型改动范围。
- 该代码只用于验证；不能直接升级为正式业务实现。

## 使用的官方技能工作流

已安装 Matt Pocock Skills 1.3.2 的 `prototype`（`LOGIC.md` 分支）：
单文件、自由操作、三个可执行引导、可读状态、模拟外部依赖。用户要求的隔离、
浏览器状态恢复和不修改 Tickets，优先于技能默认的 issue 更新建议；Git 保存仅按用户明确授权执行。
此处验证已选定方案的交互，不制作三套视觉变体。

同包支持 `handoff`：用于把后续会话目标和已有成果引用整理到操作系统临时目录，
供新代理接续；它不是发布、实现或 Git 提交流程。本轮没有启动其他代理或聊天。
